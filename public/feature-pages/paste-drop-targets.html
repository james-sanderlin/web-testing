Paste & Drop Targets

Text-like targets that receive a pasted or dropped file (e.g. a screenshot pasted as image.png) and do different things with it. Every case logs the raw event, what the browser did by default, and any network request the page made, so you can compare an upload audit against what actually left the machine. Clipboard screenshots arrive as a file named image.png; files dragged from Finder/Explorer keep their real name.

Scan check: the Island browser holds a paste or drop until its file scan finishes. Each card shows how long the event took to arrive after Cmd/Ctrl+V (or the last real dragover): over 150 ms means it was held for a scan. Use the keyboard shortcut to paste, not the context menu. Compare against plain Chrome to see the unscanned baseline.
